
# ⚔️ Escrevendo as Classes de um Jogo

Desafio prático desenvolvido durante os estudos
na Digital Innovation One (DIO).

## 📌 Objetivo

Criar uma classe genérica que represente um herói
de uma aventura, utilizando propriedades e métodos
para definir seu comportamento de ataque conforme
seu tipo.

## 🧠 Conceitos praticados

- Variáveis
- Operadores
- Laços de repetição
- Estruturas condicionais
- Funções
- Classes e Objetos
- Construtores e Métodos

## 🦸 Características do Herói

Cada herói possui três propriedades:

| Propriedade | Descrição |
|---|---|
| nome | Nome do personagem |
| idade | Idade do personagem |
| tipo | Classe do herói |

## ⚔️ Tipos de Ataque

| Tipo | Ataque |
|---|---|
| Mago | Magia |
| Guerreiro | Espada |
| Monge | Artes marciais |
| Ninja | Shuriken |
